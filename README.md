# 消失的第十三幕 — 魔術師林默的最後房間

一個無後端的靜態網頁 3D 密室逃脫。26 個互動節點、三線並行、雙結局。
改編自同名實體密室執行計畫。

> 你們是劇院檔案修復小組。清場系統會在六十分鐘後抹除最後一場排練的全部紀錄。
> 找回代表光、聲、物的三枚真相徽記，重演第十三幕，並決定是否公開他留下的證據。

## 部署到 GitHub Pages

這個專案沒有建置步驟，把檔案推上去就能玩。

```bash
# 1. 建一個新的 repo，把這個資料夾的內容全部放進去
git init
git add .
git commit -m "消失的第十三幕：網頁 3D 版"
git branch -M main
git remote add origin https://github.com/<你的帳號>/<repo 名稱>.git
git push -u origin main
```

```
# 2. 在 GitHub 上：Settings → Pages
   Source: Deploy from a branch
   Branch: main / (root)   ← 選 root，不是 /docs
```

約一分鐘後開啟 `https://<你的帳號>.github.io/<repo 名稱>/` 即可。

**注意事項**

- `.nojekyll` 一定要留著。GitHub Pages 預設會用 Jekyll 處理，底線開頭的檔案會被忽略；
  這個檔案（空的）能關掉該行為，避免日後新增檔案時踩雷。
- 網址結尾要有斜線或直接指向 `index.html`。所有路徑都是相對路徑，放在子目錄也沒問題。
- three.js 從 CDN 載入（unpkg → jsDelivr → esm.sh 依序備援），第一次開啟需要網路。
  想完全自行託管，見下方「離線／自行託管」。

### 開不起來或畫面全黑？

先開 **`diagnose.html`**（例如 `https://你的帳號.github.io/repo/diagnose.html`）。
那一頁不依賴遊戲的任何檔案，會逐項回報協定、WebGL、three.js CDN、localStorage、
音訊與觸控偵測結果，並畫兩顆對照物件讓你判斷是「太暗」還是「壞了」：

| 對照圖的狀況 | 意思 |
|---|---|
| 金色方塊與灰球都看得到 | 一切正常。遊戲偏暗就把「畫面亮度」往右拉 |
| 只看到金色方塊 | WebGL 正常但燈光／曝光有問題 |
| 兩顆都看不到（純黑） | WebGL 繪製失敗，請開啟瀏覽器的硬體加速或換瀏覽器 |

也可以用 `index.html?debug=1` 開啟遊戲，畫面下方會顯示 three.js 版本、FPS、
曝光值、光源數量與節點進度。

最常見的原因是**用 `file://` 直接雙擊開啟 index.html**——ES Module 會被 CORS 擋掉。
遊戲現在會在 8 秒後自己顯示這個說明，不會再留一片黑。

### 本機預覽

因為使用 ES Module，**不能直接用 `file://` 打開**（瀏覽器的 CORS 政策會擋）。
起一個本機伺服器即可：

```bash
python3 -m http.server 8000
# 或
npx serve .
```

然後開 `http://localhost:8000/`。

### 離線／自行託管 three.js

```bash
mkdir vendor
curl -o vendor/three.module.js https://unpkg.com/three@0.160.0/build/three.module.js
```

然後把 `js/core/three.js` 裡的 `USE_LOCAL_FIRST` 改成 `true`。

## 操作

| 按鍵 | 功能 |
|---|---|
| **W A S D**（或方向鍵） | 走動 |
| **滑鼠左鍵拖曳** | 環顧四周 |
| **點擊** 或 **E** | 互動（畫面中央會顯示物件名稱） |
| **L** | 切換滑鼠鎖定（喜歡 FPS 手感的話） |
| **U** | UV 燈開關（取得後） |
| **I** | 線索本（自動記錄所有找到的線索與道具） |
| **H** | 排練備忘（三級提示，不限次數） |
| **M** | 靜默感測時改用麥克風判定（選用） |
| **Esc** | 選單／關閉近景面板 |
| **Shift** | 快走 |
| **空白鍵** | 跳過開場旁白 |

腳步序列（G05）是**站上腳印停一下**才算一步，路過不會誤觸；
踩到不對的腳印會先轉紅警告，你有時間退開。

### 手機／平板

觸控裝置會自動顯示螢幕控制：

- **左下角搖桿**：走位（可與看四周同時操作）
- **在畫面上拖曳**：環顧四周
- **右下角「互動」**：觸發準心（畫面中央）對到的機關；也可以直接點物件
- 另有 **UV**、**線索**、**提示** 三個快捷鈕

在選單的「螢幕搖桿」可改成「一直顯示」或「關閉」；
也可以用網址參數強制：`?touch=1` 開、`?touch=0` 關。

### 覺得太暗

房間本來就暗（序幕只有一盞桌燈），但不同螢幕差異很大。
**標題畫面與暫停選單都有「畫面亮度」滑桿**，會即時調整並記住設定。

**難度模式**（標題畫面選擇）

- 標準 60 分 — 對應實體版的標準場次
- 新手 75 分 — 對應實體版的新手友善模式
- 排練模式 · 無時限 — 只計時不倒數，適合純粹解謎或做內容驗收

進度會自動存在瀏覽器（localStorage），關掉分頁再回來可以「繼續上一場」。

## 想改內容的話

| 想改什麼 | 改哪裡 |
|---|---|
| 謎題答案（密碼、音序、角度、腳步） | `js/config.js` 的 `ANSWERS` |
| 節點文案、三級提示、線索、台詞、結局 | `js/state/nodes.js` |
| 房間尺寸、玩家速度、視角靈敏度 | `js/config.js` 的 `ROOM` / `PLAYER` |
| 顏色、字體、版面 | `styles/base.css` 的 `:root` token |
| 燈光強度、環境光、曝光預設值 | `js/world/room.js` 的燈光區段、`js/core/engine.js` |
| 道具與牆面的造型 | `js/world/*.js` |
| 謎題規則與判定 | `js/puzzles/*.js` |

3D 物件與謎題規則刻意分開：`world/` 只管外觀，`puzzles/` 只管規則，
中間只透過 `game.trigger('S03', { rope: 2 })` 溝通。要抽換機關時不必兩邊一起改。

詳細架構請看 [`docs/架構與設計說明.md`](docs/架構與設計說明.md)。

## 開發用工具

```bash
node tools/check-imports.mjs      # 檢查 31 個模組的語法、import 路徑、具名匯出
```

無頭瀏覽器測試（需要 puppeteer 與 Chrome，僅開發環境需要）：

```bash
node tools/test/all.mjs           # 全部（含玩家模擬，約 12–15 分鐘）
node tools/test/all.mjs quick     # 只跑快的那幾組（約 3 分鐘）
node tools/test/all.mjs sim       # 只跑三段玩家視角模擬

# 個別執行
node tools/test/overlay.mjs       # 遮罩與點擊穿透（防止「畫面全黑」重演）
node tools/test/lighting.mjs      # 燈光預算：太暗與過曝的雙向保護
node tools/test/maze.mjs          # 磁鐵迷宮的連通性（曾經出過無解的迷宮）
node tools/test/usability.mjs     # 可用性稽核：每個互動點的螢幕大小、可及性、仰角
node tools/test/touch.mjs         # 螢幕搖桿、多點觸控、亮度設定
node tools/test/prototype.mjs     # 單一檔案原型
node tools/test/robustness.mjs    # 韌性檢查（錯誤輸入、存讀檔、倒數結束、雙結局）
node tools/test/playthrough.mjs   # 腳本驅動走完 26 個節點
node tools/test/user-sim-1.mjs    # 玩家模擬：序幕與光影線
node tools/test/user-sim-2.mjs    # 玩家模擬：聲音線與物理線
node tools/test/user-sim-3.mjs    # 玩家模擬：合流與終幕
```

「玩家視角模擬」只用玩家真的做得到的動作：按 WASD 走路（含自動繞開障礙）、
拖曳滑鼠轉視角、把游標移到物件上再點擊、以及點面板裡的按鈕。
完全不呼叫 `game.trigger` 或 `store.complete`，所以它驗的是「照著遊戲給的提示，
玩家真的走得完嗎」。

測試會攔截 three.js 的 CDN 請求並換成 `tools/test/three-stub.js`，
所以能在沒有 GPU／沒有網路的環境驗證邏輯（但不驗證畫面）。
`tools/` 與 `docs/` 不影響部署，可以留著也可以刪掉。

## 另附：單一檔案原型

`prototype/index.html` 是一個獨立的最小原型，不依賴專案其他檔案：

- 3D 房間 + 第一人稱（WASD 移動、滑鼠拖曳環顧）
- 中央金色方塊代表中央自動機，三面牆各一個彩色方塊代表三條支線
- Raycaster 點擊偵測；點擊代表「聲音區」的方塊會 `alert("你觸發了票根電話謎題")`

適合當作教學範例或改造起點。

## 技術與相容性

- three.js 0.160.0（僅核心，不使用任何 `examples/jsm` 附加元件）
- 原生 ES Module，無打包工具、無相依安裝
- 零二進位資源：貼圖用 Canvas 2D 生成，音效用 Web Audio 合成，字體用系統明體
- 需要 WebGL2 與 ES2022（頂層 await）：Chrome 89+／Edge 89+／Firefox 89+／Safari 15+
- 桌機與手機皆可：觸控裝置會自動顯示螢幕搖桿與動作鈕
- 尊重 `prefers-reduced-motion`；提供音量與視角靈敏度設定
- 內含閃光與突發聲響提示（標題畫面已註明）
